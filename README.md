# Portfolio

Personal engineering portfolio website for **Hashin Gayasha Maharambage** — a Mechatronics Engineering undergraduate at Curtin Colombo, showcasing experience, projects, and skills across industrial automation, PLC/SCADA, FPGA, robotics, and embedded systems.

🔗 **Live site:** [hashin2003.github.io/Portfolio](https://hashin2003.github.io/Portfolio/)

## Sections

- **About** — introduction and background
- **Experience** — relevant work/industry experience
- **Projects** — engineering and software projects
- **Skills** — technical skills and tools
- **Education** — academic background
- **Achievements** — awards and recognitions
- **Contact** — ways to get in touch

## Built With

- HTML5, CSS3, JavaScript (vanilla)
- Google Fonts (Sora, Inter, JetBrains Mono)
- Hosted with [GitHub Pages](https://pages.github.com/)

## Project Structure

| File | Description |
|---|---|
| `index.html` | Main page markup and content structure. |
| `styles.css` | Site styling, including light/dark theme support. |
| `script.js` | Interactivity — navigation, theme toggle, etc. |
| `projects-data.js` | Project data rendered into the Projects section. |
| `resume.pdf` | Downloadable résumé. |
| `563A6831.JPG` | Profile/portfolio image. |

## Running Locally

Clone the repo and open `index.html` in a browser — no build step required:

```bash
git clone https://github.com/Hashin2003/Portfolio.git
cd Portfolio
```

Then open `index.html` directly, or serve it locally:

```bash
python -m http.server 8000
```

and visit `http://localhost:8000`.
