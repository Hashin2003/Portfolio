Automation of BPE Folding Machine

Problem

  • The BPE (Body Protective Equipment) folding process was heavily dependent on manual labour.
  • Manual folding resulted in lower efficiency, inconsistent output, and higher labour requirements.
  • The Global Engineering and Manufacturing Technology Department identified the necessity for an automated folding mechanism.
  • Since no previous machine designs existed, the system had to be built from scratch.

Solution and Outcome

  • Worked on the project from the concept stage to completion.
  • Helped design the mechanical system and supported prototype building and assembly.
  • Developed the control system using an Omron CP1E PLC and CX Programmer.
  • Added a soft-start pneumatic valve to pressurise the system and improve safety during startup slowly.
  • Installed and wired limit switches for the BPE folding bed.
  • Installed pneumatic tubing between valves and actuators for the folding system.
  • Installed 20 reed switches for 10 pneumatic actuators and connected them to PLC inputs for position monitoring.
  • Set up RS-232 communication between the PLC and HMI.
  • Designed and programmed the HMI using Kinco HMI Ware, including Auto/Manual modes, Start/Stop, Home position, and Emergency Stop.
  • Performed testing, troubleshooting, and final commissioning of the machine.

Advanced Digital Design Project — Automated Crazy Machine

Project Overview

Designed and developed a fully automated electromechanical Crazy Machine module that transports a steel ball through a themed bank robbery sequence without human intervention. The system combines FPGA-based control, embedded systems, mechanical design, and automation to execute a complex sequence involving elevators, doors, vault mechanisms, and a final escape system. The machine was controlled using an Altera FPGA running a VHDL-based finite state machine (FSM), with an Arduino Mega supporting additional I/O functions such as OLED display control and motor operation.

Technical Highlights

FPGA-Based Automation Control
  • Developed a complete autonomous control system using VHDL on an Altera FPGA development board.
  • Implemented a finite state machine architecture to coordinate sensor inputs, timing sequences, and actuator outputs.
  • Designed modular VHDL controllers for servo motors, stepper motors, elevators, doors, buzzer, and retrieval mechanisms.
  • Used sensor feedback and timed state transitions to ensure each mechanism operated in the correct sequence.
Mechanical System Design

Designed and integrated a compact 40cm × 40cm × 40cm mechanical system consisting of:

  • Dual elevator mechanisms
  • Servo-controlled doors
  • Maze pathways
  • Vault section
  • Electromagnet retrieval mechanism
  • Final DC motor escape mechanism

Created custom mechanical components using SolidWorks and manufactured precision parts using 3D printing. Improved mechanical reliability through CAD-based validation, alignment testing, and iterative design improvements.

Sensor and Actuator Integration

Sensors:

  • IR sensors for ball detection
  • LDR + laser system for optical detection
  • Limit switches for elevator position feedback

Actuators:

  • NEMA 17 stepper motors for elevator movement
  • Servo motors for doors and mechanical mechanisms
  • Electromagnet for object retrieval
  • N20 DC motor for final output mechanism

High-current devices were controlled through dedicated driver circuits to protect the FPGA and ensure reliable operation.

Challenges & Solutions

  • Challenge: Sensor false triggering during initial detection.
    Solution: Replaced the vibration sensor with an IR sensor system to improve reliability and prevent unwanted activation caused by external disturbances.
  • Challenge: Unstable elevator movement and stepper control.
    Solution: Corrected motor wiring issues and implemented 1/16 microstepping using A4988 drivers to achieve smoother and more accurate elevator movement.

Outcome

Successfully developed and demonstrated a fully autonomous Crazy Machine system capable of transporting the steel ball through the complete bank robbery sequence within the required operating time. The final system integrated mechanical design, FPGA-based digital control, sensor feedback, and embedded programming into a reliable automated platform. The project strengthened practical experience in FPGA development, automation, CAD modelling, electromechanical integration, and system-level debugging.
